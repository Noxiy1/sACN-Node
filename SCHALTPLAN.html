MAX485 Modul - Pinbelegung

MAX485 Module Pin-Übersicht (von vorne):

  1 ● ● ● ● 8
  2         7
  3         6
  4 ● ● ● ● 5

┌─────────────────────────────────────┐
│ Pin │ Signal │ Beschreibung        │
├─────────────────────────────────────┤
│  1  │ GND    │ Masse               │
│  2  │ DI     │ Data In (vom UART)  │
│  3  │ RO     │ Receiver Out        │
│  4  │ RE     │ Receiver Enable     │
│  5  │ DE     │ Driver Enable       │
│  6  │ DO     │ Driver Out (nicht)  │
│  7  │ A      │ RS485 A (DMX+)      │
│  8  │ B      │ +5V oder RS485 B    │
└─────────────────────────────────────┘

Typische Verbindung:
┌────────────────────────────┐
│ ESP32 UART        MAX485   │
├────────────────────────────┤
│ TX (GPIO)  ──→ Pin 2 (DI) │
│ RX (GPIO)  ──→ Pin 3 (RO) │
│ GPIO EN    ──→ Pin 4+5    │
│ GND        ──→ Pin 1 (GND)│
│ +5V        ──→ Pin 8 (+5V)│
└────────────────────────────┘
            ↓
        DMX XLR
┌────────────────────────────┐
│ Max485 → XLR  (Female)     │
├────────────────────────────┤
│ Pin 7 (A) ──→ Pin 2 (+)   │
│ Pin 6 (B) ──→ Pin 3 (-)   │
│ GND       ──→ Pin 1 (Erd)  │
└────────────────────────────┘

⚡ Stromversorgung

Externe 5V Stromversorgung (mind. 1A)
         │
    ┌────┴────┐
    │  +5V    GND
    │   │      │
    │   ├──────┤
    │   │      │
    ├───┤ Schiene im Gehäuse
    │   │      │
    ├─ ESP32  (Pin VDD, GND)
    ├─ MAX485 (Pin 8 u. Pin 1, alle 4 Module!)

⚠ WICHTIG:
✓ ALLE MAX485 Pin 1 (GND) MÜSSEN verbunden sein
✓ ALLE MAX485 Pin 8 (+5V) MÜSSEN verbunden sein
✓ Kurze, dicke Drähte verwenden
✓ Keine Lötlücken oder kalten Lötstellen!
✓ Stromstärke: Insgesamt max. 2A

Stromverteilung pro Gerät:
- ESP32:   ~150 mA
- MAX485:  ~80 mA (alle 4)
- LEDs:    ~100 mA (RGB status)
─────────────────────
  Gesamt:  ~330 mA (Sicherheitsmarge: 500-1000 mA)

DMX XLR-3 Konnektoren

Weibliche XLR-3 Buchse (DMX Ausgang):

      ╔════════╗
      ║  1   3 ║  ← Blick von vorne
      ║    2   ║
      ╚════════╝

Pin 1 (oben links):  GND / Schirm (schwarz)
Pin 2 (unten):       DMX+ / Data+ (weiß oder rot)
Pin 3 (oben rechts): DMX- / Data- (blau oder grün)


Lötanleitung für XLR Buchse:
┌──────────────────────────────────┐
│ XLR-Buchse Rückansicht (innen):  │
│                                  │
│  [1-GND]      [3-DMX-]          │
│        [2-DMX+]                 │
│                                  │
│  Lötringe: jeweils ca. 1-2mm²   │
│  Drahtdicke: 0,35-0,5 mm²       │
│  Zinn: Bleifreies Lot 60/40     │
│  Temp: 350°C, ca. 3-5 Sekunden  │
└──────────────────────────────────┘

Signal-Pegel (RS485):
- Differenziell (A-B): -12V bis +12V
- Ruhezustand: ~2.5V
- MAX485 wandelt 3.3V TTL → RS485


Länge der Anschlussdrähte:
- Von MAX485 zu XLR: max. 10-15 cm
- Bei längeren Strecken: abschirmen

Detaillierte Stromverteilung

⚠️ WICHTIGE SICHERHEITSHINWEISE:
  • Niemals 12V oder höher direkt am ESP32 anschließen!
  • Alle Masseleiter (GND) müssen verbunden sein
  • MAX485 Module BRAUCHEN 5V - nicht 3.3V!
  • Spannungsregler verwenden, wenn externe Stromquelle über 5.5V
  • Gute Lötarbeiten sind essentiell - keine Kaltlötstellen!
  • RJ45 Ethernet: Vorsicht vor PoE (Power over Ethernet) - kann vorhanden sein!
